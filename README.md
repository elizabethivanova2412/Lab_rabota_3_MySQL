# Лабораторная работа №3

## Задача 1

**Условие:** определить адреса клиентов, которые заказывали игры с доставкой.

**Решение:**

1. Из отношения заказов `З` выбираем только те записи, где способ получения — доставка:

$$R1 = \sigma_{\text{Получение} = \text{"Доставка"}}(З)$$

| Номер | Получение | ID клиента |
|-------|-----------|------------|
| 3     | Доставка  | К2         |

2. Проецируем результат на идентификатор клиента:

$$R2 = \pi_{\text{ID клиента}}(R1)$$

| ID клиента |
|------------|
| К2         |

3. Соединяем полученное отношение с отношением клиентов `К` по идентификатору клиента:

$$R3 = R2 \bowtie_{R2.\text{ID клиента} = К.\text{ID клиента}} К$$

| ID клиента | Фамилия | Имя    | Адрес                  |
|------------|---------|--------|------------------------|
| К2         | Швыркин | Михаил | ул. Васи Зайцева, 14-6 |

4. Оставляем только адрес:

$$R4 = \pi_{\text{Адрес}}(R3)$$

| Адрес                  |
|------------------------|
| ул. Васи Зайцева, 14-6 |

**Ответ:** адрес клиента — ул. Васи Зайцева, 14-6.

## Задача 2

**Условие:** определить название и производителя игры, в которую можно играть самой большой компанией.

**Решение:**

1. Из отношения игр `И` выбираем нужные атрибуты:

$$R1 = \pi_{\text{Название, Производитель, Макс игроков}}(И)$$

| Название   | Производитель | Макс игроков |
|------------|---------------|--------------|
| Диксит     | Libellud      | 6            |
| Диксит     | Asmodee       | 6            |
| Монополия  | Hasbro Inc.   | 6            |
| Барбосики  | Asmodee       | 4            |

2. Создаём копию отношения:

$$R1' = R1$$

3. Находим игры, для которых существует другая игра с большим максимальным числом игроков:

$$R2 = R1 \bowtie_{R1.\text{Макс игроков} < R1'.\text{Макс игроков}} R1'$$

Затем оставляем атрибуты исходного отношения:

$$R3 = \pi_{R1.\text{Название, Производитель, Макс игроков}}(R2)$$

| Название  | Производитель | Макс игроков |
|-----------|---------------|--------------|
| Барбосики | Asmodee       | 4            |

4. Удаляем такие игры из исходного списка:

$$R4 = R1 \setminus R3$$

| Название  | Производитель | Макс игроков |
|-----------|---------------|--------------|
| Диксит    | Libellud      | 6            |
| Диксит    | Asmodee       | 6            |
| Монополия | Hasbro Inc.   | 6            |

5. Оставляем только название и производителя:

$$R5 = \pi_{\text{Название, Производитель}}(R4)$$

| Название  | Производитель |
|-----------|---------------|
| Диксит    | Libellud      |
| Диксит    | Asmodee       |
| Монополия | Hasbro Inc.   |

**Ответ:** максимальное число игроков — 6. Подходят игры «Диксит» от Libellud, «Диксит» от Asmodee и «Монополия» от Hasbro Inc.

## Задача 3

**Условие:** определить табельный номер сотрудника, который на момент выполнения запроса отвечает только за один заказ.

**Решение:**

1. Из отношения заказов `З` выбираем номер заказа и табельный номер сотрудника:

$$R1 = \pi_{\text{Номер, Таб номер}}(З)$$

| Номер | Таб номер |
|-------|-----------|
| 1     | C01       |
| 2     | C01       |
| 3     | C02       |

2. Создаём копию отношения:

$$R1' = R1$$

3. Находим сотрудников, у которых есть более одного заказа:

$$R2 = R1 \bowtie_{R1.\text{Таб номер} = R1'.\text{Таб номер} \land R1.\text{Номер} \neq R1'.\text{Номер}} R1'$$

| R1.Номер | R1.Таб номер | R1'.Номер | R1'.Таб номер |
|----------|--------------|-----------|---------------|
| 1        | C01          | 2         | C01           |
| 2        | C01          | 1         | C01           |

4. Проецируем результат на табельный номер:

$$R3 = \pi_{\text{Таб номер}}(R2)$$

| Таб номер |
|-----------|
| C01       |

5. Получаем всех сотрудников, которые назначены хотя бы на один заказ:

$$R4 = \pi_{\text{Таб номер}}(R1)$$

| Таб номер |
|-----------|
| C01       |
| C02       |

6. Вычитаем из всех сотрудников тех, кто отвечает за несколько заказов:

$$R5 = R4 \setminus R3$$

| Таб номер |
|-----------|
| C02       |

**Ответ:** сотрудник с табельным номером C02 отвечает только за один заказ.
